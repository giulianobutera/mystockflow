# MyStockFlow

App web que permite gestionar el stock de cualquier cosa, de manera simple y con la mejor visualización posible.

En esta app se pueden agregar los siguientes tipos de stock:
* Ítems simples: nombre, descripción breve y cantidad
* Categorías: nombre, descripción breve y lista de ítems simples con nombre y cantidad.

Además, una vez agregados los tipos de stock, se puede modificar la cantidad de cada ítem (ya sea si es un ítem simple o si pertenecen a una categoría) o eliminar el stock.

Se utiliza la librería [Sweetalert2](https://sweetalert2.github.io/) para el manejo de mensajes del sistema, asi como para la validar cuando se quiere eliminar un stock cargado.
